================================================================================
HOW TO USE THIS SCRIPT
================================================================================

STEP 1: PREPARE YOUR FILES
- Export your latest Excel data as a CSV and name it "chrome_laskut.csv".
- Place it in your Downloads folder.
- Ensure your "Master_Chrome.json" is also in the Downloads folder.

STEP 2: MAKE A BACKUP (CRITICAL!)
- Always make a copy of "Master_Chrome.json" (e.g., "Master_Chrome_Backup.json") 
  before running the script. The script overwrites the master file directly to 
  save you from having to rename new files every time. 

STEP 3: RUN THE SCRIPT
Option A: Using PowerShell ISE (Recommended for visibility)
   1. Right-click the .ps1 script file and select "Edit". This opens PowerShell ISE.
   2. Click the green "Play" triangle at the top (or press F5) to run the script.
   3. Look at the bottom console window for the green success message and match count.

Option B: Right-Click to Run
   1. Right-click the .ps1 script file.
   2. Select "Run with PowerShell". 
   3. A blue window will briefly appear, do the merging, and disappear when finished.

STEP 4: VERIFY
- Open your "Master_Chrome.json" file. You will now see "kuitin_nimi", "laskuID", 
  and "toimituspvm" beautifully injected into the devices that had matching serials!
