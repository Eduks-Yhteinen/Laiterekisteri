1. OVERVIEW
--------------------------------------------------------------------------------
The goal is to automate the merging of extracted invoice data into a Master JSON database. Originally designed to use Desktop flows (PAD) for PDF extraction, the architecture was pivoted to bypass Premium RPA licensing. A PowerShell script now extracts PDF data to an Excel file, and Power Automate merges this new data (kuitin nimi, laskuID, toimituspvm) into the Master JSON where serial numbers match.

2. ARCHITECTURE & DATA FLOW
--------------------------------------------------------------------------------
[PDF Invoices] -> [PowerShell Script] -> [Excel Table] -> [Power Automate] -> [Master_JSON.json]

A. SOURCE DATA
- Directory: SharePoint "Laskut" folder
- Intermediary File: Excel file containing extracted PDF data (formatted as a Table).

B. AUTOMATION (POWER AUTOMATE)
- Trigger: Scheduled/Manual
- Step 1: Initialize Array variable (varUpdatedMaster).
- Step 2: Get and Parse Master_JSON.json.
- Step 3: List rows present in Excel table.
- Step 4: Loop through Master JSON array.
- Step 5: Filter Excel array for matching serials (Excel 'serial' == JSON 'serialNumber').
- Step 6: Condition check for matches.
    - True: Merge existing JSON item with Excel row using union(), append to varUpdatedMaster.
    - False: Append original JSON item to varUpdatedMaster to preserve old data.
- Step 7: Update Master_JSON.json using string(variables('varUpdatedMaster')).

3. KEY ISSUES RESOLVED
--------------------------------------------------------------------------------
- Premium License Paywall: Bypassed the requirement for a Premium RPA Desktop Flow license by offloading PDF data extraction to a local PowerShell script.
- Nested Loops: Fixed automatic "loop within a loop" creation by correctly targeting the 'value' output from the file properties step.
- Data Loss Prevention: Added an 'Append to array' action in the False branch of the condition to ensure historical JSON data without new invoice matches isn't deleted during the file update.
- UI Glitches & Variable Errors: Resolved an 'InvalidVariableOperation' error caused by a typo in the Initialize Variable name. Fixed the New Designer hiding the array variable by forcing the mapping with an expression: string(variables('varUpdatedMaster')).
